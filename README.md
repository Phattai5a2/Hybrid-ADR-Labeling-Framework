# Hybrid ADR Labeling Framework

Official implementation of

"Hybrid ADR Labeling Framework with Expert-Validated Gold Standard and Medical Knowledge Integration"

## Overview

This repository contains the implementation of the proposed Hybrid ADR Labeling Framework for large-scale adverse drug reaction (ADR) annotation from patient drug reviews.

The framework integrates

- DeBERTa-v3 semantic inference
- Rule-based linguistic analysis
- SIDER / MedDRA knowledge validation
- Dual-Evidence Validation Mechanism
- Adaptive confidence thresholding
